# Questions to send to Rithmic and the prop firms

The design bible (sections 10 and 15) asks for these to be sent during phase 1, because the answers decide how long phase 8 (Rithmic) takes. The owner sends them; the app never contacts anyone.

Record each answer and the date at the bottom of this file.

## To Rithmic (their support or sales contact)

> Hello,
>
> I am building my own trading application for personal use and would like to connect it to Rithmic for futures trading on prop firm accounts (I am looking at Tradeify and Lucid Trading).
>
> 1. Which Rithmic API should a self-built application use (for example R | Protocol API), and how do I get access to it?
> 2. Does a self-built app need to pass a conformance or approval test before it can connect to live or prop firm accounts? If so, what does it involve and how long does it usually take?
> 3. Is there a test or demo environment I can develop against before approval?
> 4. Are there any fees for API access, the conformance process, or market data for an individual developer?
>
> Thank you.

## To each prop firm (Tradeify, Lucid Trading)

> Hello,
>
> I am considering a 25,000 account with you and would trade through Rithmic using a trading application I built myself.
>
> 1. Do you allow a self-built application to connect to your Rithmic accounts? Does it need your approval, or Rithmic's, first?
> 2. Is automated or algorithmic trading allowed on your evaluation and funded accounts? On which plans, and are there restrictions (for example on high-frequency trading or copy trading)?
> 3. What real-time market data is included with the account, which exchanges does it cover, and what does it cost per month?
> 4. Do you provide a demo or evaluation environment where I can test the connection before trading?
>
> Thank you.
